# What it is

The party the user points at. Under [Article 5](/law/eu-data-act/articles/article-05.md)
the data holder must deliver the data to it on the same terms as to the user.
Under [Article 6](/law/eu-data-act/articles/article-06.md) the recipient is bound
too: purpose-limited use, no onward sharing without agreement, and no using the
data to build a competing product.

# On the trace

The last hop in both archetypes. It is a seam and a hand, but one the customer
chose, so the ledger counts it apart from the architecture's own.
