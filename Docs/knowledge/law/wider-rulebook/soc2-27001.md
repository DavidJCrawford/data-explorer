# The question it answers

**Is the cloud disciplined with my data?**

Audited evidence of an organisation's security controls — ISO 27001 the international certificate, SOC 2 its American cousin (a report, not a certificate).

# For a facilities manager

Neither grants you rights — that's the Data Act's job. They're proof that someone independent examined the operator's controls: access, change management, incident response. As with every certificate, scope is everything: a badge on a website tells you nothing until you know which services sit inside it.

# The ask

> Which of the services my building depends on are inside the ISO 27001 scope or the SOC 2 report — and can I read the report under NDA?
