# What applies

| Question | Instrument |
| --- | --- |
| A right to the building's device data | [EU Data Act](/law/eu-data-act/overview.md) — general, all sectors |
| Personal data | [GDPR](/law/wider-rulebook/gdpr.md) |
| Supplier security as the operator's duty | [NIS2](/law/wider-rulebook/nis2.md), as transposed |
| AI that acts on people | [AI Act](/law/wider-rulebook/ai-act.md) |
| Security of the hardware | [Cyber Resilience Act](/law/wider-rulebook/cra.md) |

Member States enforce through national authorities, so remedies and penalties
vary by country ([Article 37](/law/eu-data-act/articles/article-37.md),
[Article 40](/law/eu-data-act/articles/article-40.md)).
