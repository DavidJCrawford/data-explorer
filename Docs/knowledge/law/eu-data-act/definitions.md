# Definitions

Plain readings, paraphrased. Most arguments about the Act are arguments about these words; see [Article 2](/law/eu-data-act/articles/article-02.md).

| Term | Plain reading |
| --- | --- |
| data | Any digital representation of acts, facts or information — including compilations, sound, image. |
| connected product | An item that obtains, generates or collects data about its use or environment and can communicate it — the doors, readers, sensors, meters and cameras of a connected building. |
| related service | A digital service (often the vendor's cloud/app) whose absence would stop the connected product performing one of its functions. |
| product data | Data a connected product generates that the manufacturer designed to be retrievable. |
| related service data | Data representing the user's actions/events digitised via the related service. |
| readily available data | Product/related-service data the data holder can obtain without disproportionate effort — the pool Arts. 4–5 reach. |
| user | The customer: owner, renter or lessee of the product, or recipient of the related service. |
| data holder | The party with the right or obligation to use and make available the data. |
| data recipient | A party (acting for professional purposes) to whom the data holder makes data available — including user-designated third parties. |
| data processing service | Cloud/edge computing delivered on demand — IaaS, PaaS, SaaS. |
| switching | Moving between data processing services (or to on-prem): the process Arts. 23–31 make practical and eventually free. |
| exportable data | The input/output data and metadata a switching customer is entitled to take along (with IP/trade-secret carve-outs). |
| smart contract | A program executing a data sharing agreement automatically — regulated by Art. 36's essential requirements. |
| trade secret / holder | Protected know-how within shared data: disclosure obligations carry confidentiality-preserving measures, not a bypass. |

# The two that decide everything for a building

A **connected product** is the door, the reader, the meter. A **related service** is the vendor's app or cloud without which the product would lose a function. Whether a building's head-end software counts as a related service, and whether its hosted platform is a **data processing service**, decides which chapters reach it. Both questions are fact-specific; the site gives the author's reading and says so.
