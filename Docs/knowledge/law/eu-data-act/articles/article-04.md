# Precise reading

Where data is not directly accessible from the product/service, the data holder must make readily available data (and metadata) available to the user without undue delay, free of charge, in the same quality as available to itself — continuously and in real time where applicable. Trade-secret protections apply via proportionate measures, not blanket refusal; use of the data by the data holder itself requires a contractual basis.[^eli]

*A faithful summary of the operative demand, not the statutory text.*
