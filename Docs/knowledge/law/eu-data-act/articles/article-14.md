# Precise reading

Data holders (other than small/micro enterprises) must make data available to public sector bodies, the Commission, the ECB or Union bodies that demonstrate an exceptional need to use it.[^eli]

*A faithful summary of the operative demand, not the statutory text.*

# Plain reading

The state can ask — but only through the narrow gate of exceptional need, defined next door.

*Paraphrase.*
