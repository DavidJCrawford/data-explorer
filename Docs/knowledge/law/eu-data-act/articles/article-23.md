# Precise reading

Providers of data processing services must remove pre-commercial, commercial, technical, contractual and organisational obstacles preventing customers from switching to another provider (or on-prem), porting exportable data, or using services in parallel.[^eli]

*A faithful summary of the operative demand, not the statutory text.*
