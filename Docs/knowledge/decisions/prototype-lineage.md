# History

1. **2026-07-04, frame around stewardship.** Data stewardship became the
   organising idea: the customer governs, the vendor stewards. Still true; see
   [data stewardship](/thesis/data-stewardship.md).
2. **2026-07-04, the Atlas.** A fixed-view instrument with five projections of
   the Act. Retired the same day.
3. **2026-07-04, three layers.** The Act as a living graph, the building
   animated beneath it, rights as the lens. Converged into "one view, three
   depths" and shipped as stewardship-explorer, unpromoted.
4. **2026-10-09, this project.** The argument kept, the form replaced. See
   [retire the node graph](/decisions/retire-the-node-graph.md).

What lasts from all three: rights first, the building second, the statute
third. This project keeps that order, and expresses it as a sequence in time
(landing, trace, rulebook) instead of as depth in one view.
